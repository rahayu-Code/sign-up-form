# Sign-Up Form Project

Saya sedang belajar HTML dan CSS untuk membuat sebuah **Sign-Up Form** sebagai bagian dari tugas **The Odin Project**. Proyek ini bertujuan untuk memperkuat pemahaman saya tentang:

- Struktur dasar HTML.
- Penggunaan CSS untuk styling menggunakan Flex Box.
- Formulir HTML, termasuk input, label, dan validasi.

## Tujuan Proyek

1. Membuat form pendaftaran yang fungsional.
2. Menggunakan CSS untuk membuat tampilan form yang sudah di tentukan .

## Teknologi yang Digunakan

- **HTML5**: Untuk struktur dasar form.
- **CSS3**: Untuk styling dan layout.

## Status

Proyek ini sedang dalam tahap pengembangan. Belum mengimplementasikan desain responsive karena di kurikulum ini saya belum belajar kesana.
